# Speech-provider brand marks

These assets identify speech-to-text providers in Settings → Audio.

- `googlecloud.svg`, `groq.svg`, `openai.svg`, `elevenlabs.svg`, `azure.svg`,
  `ibm.svg`, `nvidia.svg`, `apple.svg`, and `microsoft.svg` are vendored from
  `@lobehub/icons-static-svg` v1.94.0 (MIT; see `LICENSE`).
- `deepgram.svg` is from simple-icons v16.28.0 (CC0; see
  `LICENSE.simple-icons`). Its root SVG has `fill="currentColor"` and `1em`
  dimensions so it remains visible and sizeable in both themes.

The marks are bundled locally and imported as raw SVG. No third-party asset
host is contacted at runtime.
